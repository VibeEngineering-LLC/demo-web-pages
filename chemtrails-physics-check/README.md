# Физическая проверка гипотезы распыления: видимые следы за самолётами

Страница-отчёт: `index.html` (самодостаточна, рисунки встроены). Тот же текст в markdown — `REPORT.md`.

**Что проверяется.** Совместима ли гипотеза «видимые следы за самолётами — распылённое вещество» с физикой образования следов, оптикой, балансом массы, переносом, оседанием и измерениями приземного воздуха. Сравнение проводится с конденсационной моделью (следы — лёд из воды выхлопа и атмосферного пара). По каждому из шести аспектов даны доводы за и против, локальный вывод и свёрнутый блок «Пошаговый расчёт для проверки».

**Данные.** Реанализ ERA5 (WeatherBench2), статистика ICAO и IATA за 2024 год, фоновые станции сети IMPROVE (годовые файлы EPA AirData, 2000–2023).

## Воспроизведение

```
source_code_v2/chemtrail_models.py   основной расчёт (numpy, matplotlib) -> results_v2/results.json, results_table.csv, fig1–fig12
source_code_v2/era5_sac_fraction.py  доли площади с условием образования следа (xarray, zarr, fsspec; доступ к weatherbench2.storage.googleapis.com)
source_code_v2/improve_check.py      сравнение с сетью IMPROVE (pandas, requests; файлы EPA AirData) -> results_improve.json, fig13
source_code_v2/build_page.py         сборка index.html из REPORT.md и calc_blocks.json (пакет markdown)
```

Скрипты ожидают каталоги `results_v2/` и `source_code_v2/` рядом, как здесь.

## Ограничения

- Время жизни аэрозоля, норма ВОЗ для PM2.5 и погрешность массовых мониторов взяты из аннотаций и выдержек поиска; первоисточники не открывались.
- Расчёт оптики выполнен для сфер; для состава, отличного от льда, показатели преломления справочные.
- Доли ERA5 даны по площади, а не по налёту; выборка — один год (2019), сетка 1,5°.
- Станции IMPROVE — только США; приземная концентрация оценена как среднее по слою толщиной 10 км.
- Статус каждого источника (открыт / по аннотации / не открыт) указан в списке литературы страницы.
- Текст подготовлен с помощью ИИ-ассистента; ответственность за выводы — на авторе.
