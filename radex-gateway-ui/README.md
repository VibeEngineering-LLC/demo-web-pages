# Демо веб-интерфейса шлюза Radex MR107ion

Статическая демонстрация: платы нет, ответы `/api/*` подставлены демо-данными.

## Публикация на GitHub Pages

1. Положите содержимое этой папки в ветку `gh-pages` или в каталог `docs/` ветки по умолчанию.
2. Settings → Pages → Source: соответствующая ветка/каталог.
3. Файл `.nojekyll` уже лежит рядом — он нужен, чтобы Pages не пытался обрабатывать файлы Jekyll.

## Состав

- `index.html` — витрина: одна и та же страница в кадрах телефона (портрет и альбом), планшета и ноутбука.
- `app.html` — сама страница интерфейса с демо-данными. Параметры превью: `?notch=47` подставляет вырез сверху, `?left=47` — боковой, `?tab=multi` открывает нужную вкладку.
- `styles/base.css` — тема, типографика, сетки, вкладки; переносится в другие шлюзы без изменений.
- `styles/radex.css` — специфика этой страницы: графики, заключение, диагностика, сканер.

## Для прошивки

В прошивку идёт версия без демо-данных: `web/index.html` и `web/styles/` того же проекта.
