# Радоновый риск — Рациональный метод контроля радона в зданиях

Интерактивный калькулятор надёжности решения о соответствии помещения нормативу
по содержанию радона, с пошаговым описанием метода, логической схемой принятия
решения и первоисточником.

**Калькулятор (GitHub Pages), две версии:**
- научная — <https://vibeengineering-llc.github.io/radon-risk/> (полный текст

- простая — <https://vibeengineering-llc.github.io/radon-risk/simple.html>
  (то же самое обычным языком, без формул и переменных; упрощённая схема

## О методе

Нормы радиационной безопасности ограничивают **среднегодовое** содержание радона,
тогда как сам радон меняется кратно в пределах суток, недель и сезонов. Точный
ответ даёт только годовой тест, но обследовать так каждое здание экономически
недостижимо, а популярные экспрессные измерения (минуты–часы) методикой не
допускаются из-за неконтролируемой временной неопределённости.

Рациональный метод сравнивает норматив не с самим показанием прибора, а с
границей доверительного интервала оцениваемого среднегодового значения, явно
контролируя обе главные компоненты неопределённости — **временную** U_V(t)
(доминирующую) и **инструментальную** U_и. Решение принимается по двум критериям
с надёжностью не менее 95 %:

```
Критерий (1) — «соответствует»:      C(t)·[1 + √(U_V² + U_и²)] < C_ну         (§4.2.1)
Критерий (2) — «не соответствует»:   C(t)/K_p(t)·[1 − U_и] > C_ну             (§4.2.2)
Правило §7.1.2: критерий (1) не выполнен И t ≥ 9 месяцев → «не соответствует»
Иначе — «серая зона»: нужен долгосрочный тест 2–12 мес. либо меры по ALARA (§7.1.3)
```

Практическое следствие: в подавляющем большинстве зданий надёжный вывод
достигается за 2–7 суток недорогим прибором — короткий тест перестаёт быть
компромиссом.

## Возможности калькулятора

- два режима вентиляции (нормальный — от 4 суток, ограниченный — от 2 суток)
  с раздельными таблицами U_V(t);
- ввод концентрации и норматива в **Бк/м³ (ОА)**, **Бк/м³ (ЭРОА)** или **pCi/L**
  с автоматическим приведением к ОА (ЭРОА ×2 при F = 0,5; pCi/L ×37);
- пошаговый разбор решения: подстановка ваших чисел в оба критерия и в правило
  9 месяцев с пометкой, какая проверка на исход уже не влияет;
- справка: национальные нормативы (РФ / WHO / US EPA / EU) с указанием, что
  только РФ нормирует по ЭРОА; как привести паспортную погрешность прибора к k = 2;
- переключение RU / EN, светлая и тёмная тема, работает офлайн (один HTML-файл
  без внешних зависимостей).

## Как читается Таблица 1

В таблице заданы только опорные длительности (4, 5, 6, 7, 8, 10, 12, 14, 20 суток,
далее по месяцам). Если измеренное `t` попало между строками, берётся строка с
**меньшим** `t` — её значения U_V и K_p выше, то есть оценка осторожнее.
Промежуточные значения не интерполируются. Пример из источника:
для t = 4,8 суток берётся строка «4 суток», K_p = 1,74.

## Границы применимости

- Только **радон-222**. Для торона (Rn-220) аналогичная база отсутствует (§4.1.1).
- Значения U_V(t) и K_p(t) справедливы при соблюдении условий измерения раздела 5
  (режим вентиляции, размещение прибора, микроклимат).
- Юридическую силу решение имеет только при измерениях аккредитованной
  лабораторией аттестованными средствами по ГОСТ ISO/IEC 17025–2019 (§7.3.2).
  Калькулятор — вспомогательный инструмент и официальный протокол не заменяет.

## Проверка расчёта

Ядро калькулятора сверено с независимой реализацией на Python на 132 комбинациях
(режим × длительность × инструментальная неопределённость, включая граничные
t = 8/9/29/30/89/90/269/270/271/359/360 суток) — расхождений нет. Контрольный
пример практического руководства (C = 120 Бк/м³, U_и = 0,25, C_ну = 200 Бк/м³)
воспроизводится: 7 суток → серая зона (267 / 53), 6 месяцев → соответствует (182).
